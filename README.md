#Momenta

AI-powered digital photobooth that lets users capture photos and generate aesthetic photo strips directly in the browser.

##Features
- Camera Access
- Multi Photo Capture
- Photo Strip Generator
- Responsive Design
- Canvas API

##Technologies
- HTML5
- CSS3
- JavaScript
- Canvas API
- MediaDevices API

##Future Plans
- AI Filters
- Face Detection
- QR Download
- Cloud Storage
- User Accounts
